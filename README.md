# JaseChat — AI Assistant 🤖

JaseChat is an AI assistant created by Evgeny Mikhailovich Ozarko.  
It supports **5 languages**: Russian, English, Chinese, Spanish, and Japanese.

---

## 🌐 How to Use

1. Open the website  
2. Choose your language (buttons in the top right corner)  
3. Type a message  
4. JaseChat will reply!

---

## 🎯 Features

- Answers questions  
- Searches for information on the internet  
- Shows sources  
- Types responses letter by letter (like a real person)  
- Works in 5 languages  

---

## 🛠️ Technologies

- Pure HTML, CSS, JavaScript  
- Hosted on GitHub Pages  
- Runs directly in your browser
